<h2 id="about-the-project">About The Project</h2>

<p>
  <b>Lunar Lifestyle</b> is a clean, user-friendly platform designed to streamline daily activity tracking, habits, and lifestyle preferences. Built with a focus on simplicity and responsiveness, it helps users organize their routines efficiently.
</p>

<h2 id="features">Features</h2>

<ul>
  <li><b>Responsive UI:</b> Fully optimized for desktop, tablet, and mobile views.</li>
  <li><b>User Dashboard:</b> Intuitive navigation and activity management.</li>
  <li><b>Custom Management:</b> Easily create, update, and manage entries and preferences.</li>
  <li><b>Fast Performance:</b> Lightweight architecture built for high speed and reliability.</li>
</ul>

<h2 id="getting-started">Getting Started</h2>

<h3>Prerequisites</h3>

<p>Make sure you have a local web server environment installed (such as XAMPP, WAMP, or a local PHP/MySQL environment):</p>
<ul>
  <li>PHP >= 7.4</li>
  <li>MySQL / MariaDB</li>
  <li>Web Server (Apache / Nginx)</li>
</ul>

<h3>Installation</h3>

<ol>
  <li><b>Clone the repository:</b>
    <pre><code>git clone https://github.com/ASHR3FAT/Lunar-Lifestyle.git</code></pre>
  </li>
  <li><b>Navigate into the project directory:</b>
    <pre><code>cd Lunar-Lifestyle</code></pre>
  </li>
  <li><b>Database Setup:</b>
    <ul>
      <li>Import the provided <code>.sql</code> file (if applicable) into your database client (e.g., phpMyAdmin).</li>
      <li>Configure your database connection in your configuration file (e.g., <code>db.php</code> or <code>config.php</code>).</li>
    </ul>
  </li>
  <li><b>Run the application:</b>
    <ul>
      <li>Place the directory inside your web server root (e.g., <code>htdocs/</code> for XAMPP).</li>
      <li>Open your browser and visit <code>http://localhost/Lunar-Lifestyle</code>.</li>
    </ul>
  </li>
</ol>
